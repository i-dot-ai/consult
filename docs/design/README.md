# Iterative Design Records

We use Iterative Design Records to keep track of design changes as they happen. If any major change would happen to
the design that would cause a new copy to be created, then an ADR should be added. Use the 
docs/design/12-10-26-Survey Import prototype/0001-record-design-decisions.md document as a basis to create other IDR
records from. Describe the context, change done and which pages it affected, as well as a copy of the design document.
